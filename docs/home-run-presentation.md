# ホームラン表示

起点main: 5584b7b969961312ef758722ae8f68ff78a4be68。別ブランチout-visual-eventsは統合しない。

## データ・時刻

hit(p,4)の既存確定結果と進塁前の実走者数でソロ/2ラン/3ラン/満塁を決める。名前は実選手、数字はscoreHit直前のhr+1。シーズン集計ではないため「この試合N本目」と明記する。確率・乱数呼び出し・個人成績・セーブ形式は変更しない。

既存打球の最終フレーム（t=1）から表示し、飛行中は非表示。通常1400msのフライトだが実際のRAF到着まで待つ。大見出し「ホームラン！」、満塁時は「満塁ホームラン！」。別行で名前、種類、当日本塁打数を表示。球場内の上寄り中央27%、背景は深緑・金色の縁。点滅なし・入力透過。得点表示は従来の49%位置を使用し別要素で維持する。

表示は描画時計で2500ms。新しい試合・次の投球では破棄する。通常の次球待ちを延ばさないので、次の投球開始が先ならその時点で表示を終える。

## 進塁と得点

規則状態と個人成績は従来通り即時確定。表示得点は既存scoreRunnerArrivedでホーム到達ごとに1回ずつ進める。ホームランで短い既存走者の経路だけ、到達が打球着地+90ms（後続は100ms刻み）より早くならないよう出発を待つ。経路と区間速度は再利用し、打者の長い周回が従来どおり試合テンポを決める。ボール飛行・打者周回・外野手は既存描画関数を使用する。

サヨナラのfinishは規則確定・保存・ログを維持し、ホームランに限ってstopによる描画破棄を避ける。確定した全走者と打者の周回、得点表示、文字表示を続け、描画終了後に操作を無効化する。規則の試合終了時刻は変更しない。既存の保存がcreditRunsの打点更新前に呼ばれる点は今回変更しない。

## 停止・手動操作

ホームラン専用の使い捨て描画状態にRAF・タイマー・経過時間を保持する。通常プレーでは各ラッパーは従来のネイティブAPIへ委譲する。停止ではtokenを変えず、ホームランの打球・走者・文字の時計を止め、再開で続行する。停止中の1球送りは現在のホームランの残りを再生し、次の乱数判定は行わない。連打でも新しい球を消費しない。速度2/4倍は既存仕様どおり次球間隔の設定で、打球飛行・周回自体の速度は変更しない。

新しい試合・明示的stopでは状態と文字を破棄する。古いpumpはgame/token/同一状態の照合で無効となる。通常のアウト・チェンジや非HRの停止再開はこの改修の対象外。
